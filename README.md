## Overview

The **Prepositional Suitcase Compactor** identifies overloaded "suitcase sentences" containing nested prepositional chains (*of*, *for*, *in*, *with*), folding them into crisp compound nouns, possessives, and direct active verbs to restore reading velocity.

## Core Patterns

- **2-Preposition Threshold**: Flag and refactor clauses with 3+ stacked prepositions.
- **Reverse-Noun Compaction**: Fold `[A] of [B] for [C]` into `[C]'s [B] [A]`.
- **Verb Release Protocol**: Convert nominalized prepositional phrases back into active verbs.
